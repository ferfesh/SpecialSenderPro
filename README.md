# SpecialSenderPro (Alpha Team)

مستودع أدوات وتهيئة منصة سيندر برو الخاصة بفريق ألفا.

## المحتويات:
- `AlphaLauncher.exe`: لانشر تشغيل وتحديث أدوات البرنامج الثلاثة.
- `AlphaUpdater.exe`: محرك التحديث الدوري المزدوج (السيرفر الأصلي للبرنامج + جيت هب).
- `server.cert`: شهادة الأمان المعتمدة للاتصال الآمن.
- `server.conf`: ملف إعداد الاتصال بالخادم.
- `version.json`: سجل الإصدارات وتوجيه التحديثات التلقائية.
